1. Type d'analyse et DICOM

Aussi pour refaire les calculs sans les DICOM : déposez les fichiers du dossier courbes d'une analyse de perfusion (même fenêtre et même RR, résultats identiques). Un fichier .txt = un patient, nommé comme le fichier (ex. CMH-012.txt). Classeur Excel (.xlsx) : un onglet par patient, nommé avec son code ; dans chaque onglet, une colonne « Temps (s) » (ou Time [ms]) puis une colonne VD (ou RV) et une colonne VG (ou LV). Chaque export doit contenir une ROI VD (RV) et une ROI VG (LV). Résultats à part (resultats_PTT_segment.csv). Le RR est pris dans le fichier clinique, sinon dans une analyse de perfusion du même patient faite sur ce PC.
